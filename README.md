 # Cinephile

**Cinephile** es una aplicación web para visualizar, filtrar y ordenar el catálogo de películas de The Movie Database API V3. Permite a los usuarios explorar una amplia variedad de películas, visualizar sus detalles y realizar búsquedas basadas en géneros y fechas de lanzamiento.

Este proyecto fue realizado con **React** y **TypeScript**.

## Preámbulo

La manera en que consumimos películas ha cambiado con la llegada de los servicios de streaming como Netflix, HBO, Disney+, entre otros. Esto ha abierto un abanico de posibilidades para crear experiencias innovadoras utilizando datos de películas (directores, actores, géneros, fechas, etc.), lo que  inspiró a desarrollar esta aplicación.

## Resumen del proyecto

**Cinephile** permite a los usuarios explorar un catálogo de películas extraído de The Movie Database API V3. Los usuarios pueden:

- Visualizar las películas en formato de catálogo.
- Filtrar por género.
- Ordenar por año de lanzamiento (ascendente y descendente).
- Ver detalles de cada película en una página dedicada.

## Objetivos de aprendizaje

En este proyecto se abordan varias competencias técnicas, entre ellas:

- Uso de HTML semántico.
- Uso de CSS con Flexbox y Grid Layout para el diseño de la interfaz.
- Implementación de pruebas unitarias con JavaScript.
- Uso de React y TypeScript.
- Creación de una SPA (Single Page Application).
- Consumo de APIs (The Movie Database API).

## Tecnologías utilizadas

- **React**: Biblioteca de JavaScript para construir interfaces de usuario.
- **TypeScript**: Lenguaje basado en JavaScript con tipado estático.
- **CSS**: Para el diseño y maquetación de la interfaz.
- **The Movie Database API**: API para obtener datos de películas.
- **React Router**: Para manejar la navegación entre páginas.
- **Jest y React Testing Library**: Para la implementación de pruebas unitarias.

## Características

- **Catálogo de películas**: Visualiza el catálogo completo de películas.
- **Paginación**: Navega entre páginas de resultados.
- **Filtros**: Filtra por género y ordena por año de lanzamiento.
- **Detalles de película**: Consulta información detallada sobre cada película.
